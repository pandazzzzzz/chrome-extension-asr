ASR 扩展 — 流式诊断页

本页用于配合扩展做端到端调试：Live Stream（含字幕浮层）、Record Tab、 麦克风录音、Fill into page、配置保存 都会把遥测事件转发到这里。 可从本机选择音视频供 Record Tab 采集；监听可编辑字段接收 fill-text 注入并记日志； 实时诊断焦点与字段状态；可一键导出日志贴给开发。

用法：① 打开扩展 popup，选好 Qwen + API Key ② 点这个页面里的输入框获得焦点 ③ 回 popup 点 Live Stream / Record Tab / Start Recording ④ 边说边看这里：fill-text 注入会即时显示在日志区，焦点/字段诊断面板能看出注入是否生效， 上方的实时事件面板则显示扩展内部走到哪一步（`ws-connecting` → `task-started` → `result` …）。
面板顶部可按事件名过滤（如输入 ws- 只看连接相关），长跑时旧事件会被滚动丢弃（上限 2000 条）。
