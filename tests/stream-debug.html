ASR 扩展 — 流式诊断页

本页用于配合扩展进行 Live Stream / Record Tab / Fill into page 的端到端调试。 内置样例视频供 Record Tab 采集；监听可编辑字段接收 fill-text 注入并记日志； 实时诊断焦点与字段状态；可一键导出日志贴给开发。

用法：① 打开扩展 popup，选好 Qwen + API Key ② 点这个页面里的输入框获得焦点 ③ 回 popup 点 Live Stream 或 Record Tab ④ 边说边看这里：fill-text 注入会即时显示在日志区，焦点/字段诊断面板能看出注入是否生效。
